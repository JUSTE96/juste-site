CV de agent de nettoyage industriel : ce que les recruteurs attendent.

ROME K2204Services, propreté, sécurité et espaces verts

Aussi appelé : Agent / Agente d'entretien de nettoyage industriel, Agent / Agente machiniste en propreté, Agent / Agente technique de nettoyage industriel, Aide-agent / Aide-agente technique de nettoyage industriel, Chef / Cheffe d'équipe nettoyage industriel, Chef / Cheffe d'équipe propreté.

L'agent de nettoyage industriel est responsable de la propreté et l'hygiène des locaux industriels et des équipements. Réalise la remise en état des sols à l'aide de matériel mécanisé. Utilise des machines spécifiques pour le nettoyage en profondeur. Réalise l'évacuation des déchets selon les procédures environnementales. Contrôle la qualité de son travail et réajuste son intervention si nécessaire. Peut superviser une équipe de nettoyage dans de grands complexes industriels

Comment l'écrire dans votre CV

  1. L'intitulé que les recruteurs tapent. Écrivez « Agent de nettoyage industriel » tel quel en titre de CV, ou l'une des appellations courantes : Agent / Agente d'entretien de nettoyage industriel, Agent / Agente machiniste en propreté, Agent / Agente technique de nettoyage industriel.
  2. Les savoir-faire, mot pour mot. Quand c'est vrai, reprenez la formulation du référentiel, par exemple « Communiquer avec les équipes sur le terrain pour coordonner les opérations » ou « Superviser une équipe de nettoyage industriel ». Un logiciel de tri cherche ces termes, un recruteur les reconnaît.
  3. Les outils et savoirs nommés. Machines de nettoyage à injection ou extraction, Utilisation d'autolaveuses, Utilisation de monobrosse, Produits de nettoyage spécifiques : citez ceux que vous maîtrisez vraiment, dans une rubrique Compétences.
  4. Formation et accès. Cet emploi est accessible sans qualification particulière mais un Titre Professionnel, CAP Agent de propreté et d'hygiène est recommandé. Indiquez le diplôme, le titre ou la certification avec l'année ; « en cours » si c'est le cas.
  5. Des chiffres. Volumes traités, taille d'équipe, délais tenus, taux atteints : un chiffre vrai vaut mieux qu'un adjectif.
  6. Ce que vous n'avez pas. Une exigence absente de votre parcours ne s'écrit pas dans le CV. Elle se traite dans la lettre, honnêtement. Voir le guide des mots-clés.

Accès au métier

Cet emploi est accessible sans qualification particulière mais un Titre Professionnel, CAP Agent de propreté et d'hygiène est recommandé. Les formations dans le domaine de l'hygiène, de la propreté et de l'environnement peuvent être un atout.
