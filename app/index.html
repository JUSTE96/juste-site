    Le bouton « Analyser avec Juste »

    Il apparaît dans le menu Partager de Safari, sur iPhone et iPad.

    Ajouter le raccourci en un geste
    1. Autorisez les scripts des raccourcis. Réglages → Apps → Raccourcis → Avancé → activez « Autoriser l'exécution de scripts ». (Avant iOS 18 : Réglages → Raccourcis → Avancé.)
    2. Créez le raccourci. Ouvrez l'app Raccourcis, touchez +, puis nommez-le « Analyser avec Juste ».
    3. Ajoutez l'action « Exécuter JavaScript sur la page web ». Remplacez le code d'exemple par le script ci-dessous.

    Pour l'utiliser
    
        
    Sur une offre ouverte dans Safari : Partager → Analyser avec Juste. La première fois, iOS demande d'autoriser l'accès au site : choisissez « Toujours autoriser ».
    
      
    
      
    
        Sur Android ou un autre navigateur : un favori
        
    Créez un favori nommé « Analyser avec Juste » et remplacez son adresse par ce code. Sur une offre, ouvrez vos favoris et touchez-le.
